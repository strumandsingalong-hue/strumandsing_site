# Hand videos for chords (optional)

Drop short close-up clips of real hands playing each chord here, and they'll appear on that
chord's step as **"Watch real hands"**, next to RaiN's walkthrough.

- Format: `.mp4` (H.264), portrait or square, 5–15 seconds, no sound needed (or a single strum).
- Name the file after the chord shape, writing `#` as `sharp`:
  `G.mp4`, `Em.mp4`, `Cadd9.mp4`, `Fmaj7.mp4`, `Fsharpm.mp4`, `Bb.mp4`, `G-B.mp4` (for G/B)
- Film from the player's view (looking down at the neck) so it matches RaiN's fretboard,
  or from the front, mirrored, like a teacher sitting opposite.
